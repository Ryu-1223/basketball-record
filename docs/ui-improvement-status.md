## 実装した残件

- 部内ゲームの選手選択に記録先チーム名を表示。
- 主記録60px・間隔8px、戻る・相手得点・成績切替・閉じる48px以上へ調整。
- 選手名16px、注記・上部タブ14px、時計28pxへ調整。

- 復元した通常プレーの下書きでも起点ボタンを取得する。画面の再描画で復帰先の参照が消えないようにした。
- 保存後・キャンセル後の復帰を既存テストに追加。保存・時刻・集計処理は維持。

## 未実施の確認

実装済みと検証済みを区別するため、以下を未確認として残す。

- 200%文字拡大、画面回転、最大経過時間・3桁得点を同時に表示した試験。
- 5人・20人、0/00/99、部内ゲーム3モード、通信失敗時について、新しいレイアウトでの全条件の実画面確認。
- 印刷ダイアログおよび印刷物のレイアウト最終確認。
- 実スマホのキーボード、VoiceOver/TalkBack、体育館での片手操作、利用者による課題確認。
- 最新版の本番反映と反映後の動作確認。

上記のうち、ブラウザーやローカルで確認できる項目も残っている。すべてが利用者の操作待ちという意味ではない。計画全体の完了はまだ宣言しない。
